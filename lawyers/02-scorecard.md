# ٢. القرار: في أمل ولا لأ؟

بعد ما نملا [01-audit.md](01-audit.md)، ندي كل بند درجة من ٠ لـ ٢.

| البند | ٠ | ١ | ٢ | الدرجة |
|---|---|---|---|---|
| **الدافع**: عايز يتشهر؟ | مش فارق معاه | ساعات بيلمّح | بيحسد اللي مشهورين أو بيتكلم عن ده | |
| **الفلوس**: يقدر يدفع شهري؟ | لأ | أي حاجة صغيرة | بسهولة | |
| **الوصول**: توصله إزاي؟ | مفيش طريق | عن طريق وسيط | مباشر وبيعرفك | |
| **الفجوة**: الفرق بين شهرته الحقيقية وأونلاين | صغير، هو أصلاً معروف أونلاين | متوسط | كبير، ودي فرصتك | |
| **الكاميرا**: هيظهر في فيديو؟ | رافض تماماً | لو اتظبطله | بيحب يتكلم | |
| **الوقت**: هيدّي وقت للتصوير والمراجعة؟ | لأ | قليل | آه | |
| **المادة**: عنده حكايات وقضايا وخبرة؟ | قليل | عادي | كتير | |
| **المنافسين**: في ناس أقل منه أشهر منه؟ | لأ | مش واضح | آه وأمثلة قوية | |

## النتيجة

- **١٢ لـ ١٦**: كمّل بكل قوتك. اعمل العينات التلاتة.
- **٨ لـ ١١**: كمّل، بس ابدأ بعينة واحدة (التقرير) وشوف رد فعله قبل ما تتعب في الباقي.
- **أقل من ٨**: متضيعش وقتك في عينات. ابعتله رسالة قصيرة بفكرة واحدة، ولو مردش، خلاص.

## خطوط حمرا (لو واحدة منهم موجودة، القرار "لأ" مهما كانت الدرجة)

- رافض الكاميرا **و** رافض إن حد يتكلم باسمه.
- حد تاني ماسكله السوشيال وهو مبسوط منه وبيثق فيه.
- بيدفع متأخر أو معروف إنه بياكل حق الناس. النرجسي اللي عنده فلوس ممكن يبقى عميل ممتاز، أو كابوس بيطلب تعديلات للأبد. لو ده التاني، الفلوس مش هتستاهل.

> في كل الأحوال، لو كملت: **عقد مكتوب، عدد تعديلات محدد، ودفع مقدم**. مع الشخصية دي، اللي مش مكتوب هيتحسب ضدك.
